# Backup and restore

نسخة PostgreSQL يومية مشفرة إلى تخزين مستقل. الاحتفاظ: 7 يومية، 4 أسبوعية، 12 شهرية. اختبر الاستعادة ربع سنويًا: أنشئ قاعدة جديدة، استعد `pg_restore --clean --if-exists --no-owner`، نفذ فحص سلامة، ثم بدّل الاتصال ضمن نافذة صيانة. لا تعتبر النسخة ناجحة قبل تحقق checksum وتجربة استعادة.
